双击 `gallery.html` 即可本地浏览，无需安装依赖、启动服务器或联网。筛选分类后点击任意图片可放大，使用左右方向键切换，Esc 退出。卡片和灯箱中的“原 PNG”链接可直接打开对应独立效果图。

## 目录

- `gallery.html`：本地审阅图册，26 张最终效果图。
- `images/`：独立竖屏 PNG 效果图。
- `prompts/`：逐张完整生成提示词。
- `references/`：用户提供的提现风格图、当前游戏画面。
- `ART-DIRECTION.md`：统一美术方向。
- `ui-inventory.md`：界面来源、真实链路、当前配置与范围。
- `manifest.json`：最终统一交付索引（26 张）。
- `*-manifest.json`：分组生成记录。
