# Copper lock production sprite

Generated using the built-in image_gen tool from the user-approved natural wood HUD preview. The lock is independent from the tray's wood button background so the original locked/unlocked state can remain intact.

Production asset: `Assets/OrchardUI/Art/HudCopperLock.png`. `generated-original.png` is an identical copy of the generated output. `prompt.txt` records the full generation prompt, and `metadata.json` records the GUID, stable sprite file ID, original dimensions, alpha bounds, and importer rect.

The PNG is preserved without pixel edits, background removal, or rescaling. Its RGBA alpha spans 0–255. Only Unity's Sprite rect trims transparent padding, retaining an 8-pixel margin. Import size is capped at 256 on all configured platforms, with mipmaps disabled. The lock is intended for the existing 69×79 Image rect using preserveAspect.

No Prefab, scene, runtime code, event binding, game value, or UI operation was modified by this asset task.
